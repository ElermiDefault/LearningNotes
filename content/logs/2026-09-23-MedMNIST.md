## 我弄明白了什么

### 数据集的任务和结构

- PathMNIST 是一个九分类任务，不是二分类或多标签任务。九个类别包括脂肪、背景、碎屑、淋巴细胞、黏液、平滑肌、正常结肠黏膜、癌相关间质和结直肠腺癌上皮；
- MedMNIST 发布的图像数组采用 `NHWC` 排列。训练集、验证集和测试集的形状分别为 `(89996, 28, 28, 3)`、`(10004, 28, 28, 3)` 和 `(7180, 28, 28, 3)`；
- 图像类型为 `uint8`，实际像素范围为 `0–255`；标签形状为 `(N, 1)`，类型同样是 `uint8`；
- 这里检查的是 MedMNIST 缩放后的 `28×28` 图像。源数据中的图像大小是 `224×224`，因此不能把 `28×28` 称为未经处理的原始图像。

### 数据划分和类别分布

- 训练集和验证集来自 NCT-CRC-HE-100K，并按约 `9:1` 划分；测试集 CRC-VAL-HE-7K 来自另一个临床中心；
- 因为测试集不是从训练数据中随机留出，测试表现不仅反映模型分类能力，还可能受到不同中心的染色、制片和扫描条件影响，更接近跨中心泛化测试；
- 训练集和验证集的类别比例几乎一致：两者样本最少的都是正常结肠黏膜，约占 `8.77%`，最多的都是结直肠腺癌上皮，约占 `14.3%`；
- 测试集的类别分布明显不同。碎屑类只有 `339` 张，占 `4.72%`，脂肪类有 `1338` 张，占 `18.64%`。因此只看总体准确率可能掩盖少数类别的表现，后续还需要查看各类别指标和宏平均指标。

### NPZ 文件和数据泄漏问题

`pathmnist.npz` 只包含以下六个数组：

```text
train_images, val_images, test_images,
train_labels, val_labels, test_labels
```

文件中没有患者 ID、切片 ID 或图块来源信息。因此，仅凭当前 NPZ 文件无法独立检查同一患者或同一切片的图块是否跨越训练集和验证集。无法检查不等于已经存在数据泄漏，也不等于已经证明不存在泄漏。

### Python 和 NumPy 用法

- 使用 `pathlib.Path` 和 `/` 运算符组合路径，并用 `mkdir(parents=True, exist_ok=True)` 安全创建目录；
- 使用字典推导式批量建立三个数据集；
- 使用 `reshape(-1)` 将 `(N, 1)` 标签展平，使用带有 `minlength=9` 的 `np.bincount()` 保证九个类别都会出现在统计结果中；
- 使用 `enumerate()` 同时取得类别编号和计数，并用格式化字符串对齐输出；
- 使用 `np.random.default_rng(seed=42)` 固定随机抽样结果，再通过 `np.flatnonzero()` 找到指定类别的所有候选索引；
- 使用 `axes.flat` 遍历 `3×3` 子图，完成每类一张图像的检查。

## 还没有解决的问题

1. 由于 NPZ 文件缺少患者和切片标识，目前不能独立进行患者级或切片级数据泄漏审计；
2. 每类只查看一张图，只能帮助建立直观认识，不能代表类内差异，也不能证明哪些类别一定容易混淆；
3. 多个组织类别都呈现相近的粉紫色纹理。它们是否真的难以区分，需要在训练模型后通过混淆矩阵和错误样本分析确认。
